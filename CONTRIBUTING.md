# Contributing Guidelines

Thank you for your interest in contributing to **Stellar Assault — 2D Space Shooter**!

## 🚀 Development & Test Workflow

1. **Clone the Repository**
   ```bash
   git clone https://github.com/SriniwasAwasthi/stellar-assault-space-shooter.git
   cd stellar-assault-space-shooter
   npm install
   ```

2. **Run Dev Server**
   ```bash
   npm run dev
   ```

3. **Run Automated Physics & Collision Tests**
   ```bash
   npm test
   ```

4. **Submit a Pull Request**
   - Ensure all physics engine tests pass cleanly.
   - Use conventional commit messages (`feat:`, `fix:`, `test:`, `docs:`).
